Title: TrianglesNo2 - Audio-reactive Sierpinski fractal with drum-triggered corner explosions

Description:
Watch as audio-reactive Sierpinski triangles evolve with the melody while kick and snare hits trigger explosive mini-triangles in the corners. This generative art piece synchronizes fractal geometry, color shifts, and background washes to create a hypnotic audiovisual experience built with p5.js, WebGL, and Tone.js.

Key elements:
- Main Sierpinski fractal that evolves with musical cues
- Drum-reactive mini-triangles in corners (kick bottom-left, snare bottom-right)
- Color tetradic schemes that reset on specific musical cues
- Full-screen background envelopes that pulse with sustained notes
- Precise audio-reactivity using FFT analysis and MIDI-triggered events

Built with: p5.js, WebGL, Tone.js
Audio: Original composition in Reason Studios
Technique: Audio-reactive generative art
